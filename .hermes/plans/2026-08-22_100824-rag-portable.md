# RAG portable — Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.
> Chat FR. Commits: identité locale `LeVibeux <ametois@proton.me>` uniquement. Pas de remote / pas de push sauf demande.

**Goal:** Finir un kit RAG **local, généralisable, portable** : on copie le dossier `RAG/` dans n’importe quel dossier de travail ; un agent (ou un humain) appelle uniquement `ingest.py` / `search.py` (JSON stdout).

**Architecture:** Embedder **dense** unique (Ollama EmbeddingGemma) + **BM25 lexical** (SQLite FTS5). Pas de sparse appris (SPLADE), pas de late interaction (ColBERT), **pas de rerank** (ni MiniLM ni Ollama). Chunk défaut `parent_child`. Query = rewrite/HyDE (`qwen3.5:0.8b`) → dense + BM25 → fusion RRF → hits + métadonnées. **Pas de Docker. Pas d’agents dans le kit. Pas de types métier.**

## Décisions déjà figées (ne pas rouvrir)

1. Local only. **Même** embedder à l’index et à la query (`embeddinggemma`).
2. Retrieval = **dense** (Gemma) + **BM25 lexical**. Pas SPLADE, pas ColBERT.
3. **Pas de rerank** (ni cross-encoder, ni `rerank: ollama`). Fusion RRF seulement.
4. Query : question originale **gardée** + 2–3 reformulations + HyDE (`qwen3.5:0.8b`). `--no-rewrite` / fallback si Ollama down.
5. Chunk défaut **`parent_child`** (child ~256 indexé, parent ~1024 renvoyé). Alts : `section`, `window`. Pas de semantic / late-chunking / RAPTOR.
6. Meta par hit : `path`, `page` (PDF), `locator` (titre / Article), `collection`. Pas de champs métier (juridiction, etc.).
7. Portable = dossier `RAG/` copiable + `indexes/` dans le workdir. Usage : `<workdir>/docs/` + `<workdir>/RAG/`. Scripts seulement ; pas d’agent dans le kit.
8. Collections = noms de dossiers, pas des domaines.
9. `~/Build/exemple/` — **supprimé**. Code uniquement dans `~/Build/RAG_build/`.
10. Pas Docker / Qdrant / torch.

### Pipeline figé

```
ingest :  docs → parent_child → /api/embed (embeddinggemma) → SQLite (vecteur + texte + page/locator/path)
query  :  question → rewrite+HyDE (0.8b) → embed Gemma + BM25 → RRF → JSON hits
```
